How to use

Random project names, built from words in different categories.

In the browser

  1. Choose 2 words or 3 words.
  2. Press Generate 1 Name, Generate 10 Names or Space.
  3. Use Copy on a name, or Copy All for a batch.
  4. Press ☆ to save a name as a favorite. Favorites live in your browser only. Export .txt downloads them as a file.
  5. Press .com? to check whether the matching domain name is free (opens whois.com).

How names are made

Each name follows a natural pattern, for example an adjective followed by a metal and an animal: Silent Iron Wolf. No two words in a name come from the same category. Every choice uses the cryptographically secure random generator (crypto.getRandomValues), so names are not predictable. Nothing is stored on the server, so the same name can turn up again, but there are about 5 million different 3-word names.

API

GET /api/generate?count=10&words=3
ParameterValuesDefault
count1 to 50 (other numbers are clamped)1
words2 or 33

Invalid values fall back to the defaults instead of causing an error. Example:

curl "/api/generate?count=2&words=3"

Response:

{
  "count": 2,
  "words": 3,
  "results": [
    { "name": "Silent Iron Wolf",
      "words": ["Silent", "Iron", "Wolf"],
      "categories": ["adjectives", "metals", "animals"] }
  ]
}

Limit: 60 API requests per minute per IP address. Above that you get HTTP 429 and a Retry-After header. The API accepts GET requests only.

Security

The site is served over HTTPS only. Plain HTTP requests are redirected, and browsers are told to remember that (HSTS).
